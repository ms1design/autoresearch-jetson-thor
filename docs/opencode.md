# OpenCode Integration Guide

This document explains how to use the OpenCode integration for the autoresearch-jetson-thor project.

## Overview

The project has been integrated with OpenCode to enable autonomous LLM training research. This integration includes custom tools, subagents, and project structure configuration.

## Prerequisites

- **OpenCode**: Installed (https://opencode.ai/docs)
- **Docker & Docker Compose**: For containerized training
- **Jetson AGX Thor**: Target platform with JetPack 7.x
- **Python 3.12**: With `uv` package manager

## Installation

1. **Install OpenCode**:
   ```bash
   npm install -g opencode-ai
   # or use other installation methods from https://opencode.ai/docs
   ```

2. **Navigate to project**:
   ```bash
   cd /home/narandill/autoresearch-jetson-thor
   ```

3. **Initialize OpenCode**:
   ```bash
   opencode
   # Then in the TUI:
   /init
   ```

## Available Tools

### 1. train (train.ts)

Execute training experiments with the Jetson Thor autoresearch setup.

**Arguments**:
- `experiment_name`: Name of the experiment for logging (required)
- `description`: Description of what changes or parameters are being tested (required)

**Usage**:
```typescript
// In OpenCode conversation
train("experiment-1", "Test learning rate of 0.04")
```

**Returns**:
```json
{
  "success": true,
  "experiment": "experiment-1",
  "description": "Test learning rate of 0.04",
  "results": {
    "val_bpb": 0.9979,
    "peak_memory_mb": 45060.2,
    "training_seconds": 300.1,
    "raw_output": "..."
  }
}
```

### 2. analysis (analysis.ts)

Analyze training results from the Jetson Thor autoresearch setup.

**Arguments**:
- `log_file`: Path to training log file (default: `run.log`)
- `results_file`: Path to results.tsv file (default: `results.tsv`)

**Usage**:
```typescript
// Analyze last experiment
analysis()

// Analyze specific log file
analysis("/home/narandill/autoresearch-jetson-thor/run.log", "results.tsv")
```

**Returns**:
```json
{
  "log_analysis": {
    "val_bpb": 0.9979,
    "peak_memory_gb": 44.0,
    "training_seconds": 300.1,
    "success": true
  },
  "results_analysis": {
    "total_experiments": 5,
    "valid_experiments": 4,
    "best_result": {...},
    "status_breakdown": {...}
  }
}
```

### 3. build-image (build-image.ts)

Build the training Docker image with all dependencies synced.

**Arguments**:
- `tag`: Docker image tag (default: `latest`)
- `force_build`: Force rebuild even if image exists (default: `false`)
- `verbose`: Show verbose output during build (default: `false`)

**Usage**:
```typescript
// Build with default settings
build-image()

// Build with custom tag
build-image({ tag: "v1.0.0" })

// Force rebuild
build-image({ force_build: true })
```

## Available Subagents

### 1. python-coder

**Purpose**: Modify train.py for autonomous research experiments

**Focus**: 
- Model architecture changes
- Hyperparameter tuning
- Training loop improvements

**Key Constraints**:
- Only modifies `train.py`
- Must improve val_bpb (lower is better)
- 5-minute time budget per experiment

**Tools Available**:
- read, write, edit, bash, grep
- train, analysis (custom tools)

**Use Cases**:
- "Change learning rate from 0.02 to 0.04 and run experiment"
- "Try reducing model depth from 8 to 6 layers"
- "Implement gradient accumulation to increase batch size"

### 2. arxiv-researcher

**Purpose**: Find and analyze academic papers from arXiv.org

**Focus**:
- LLM training research
- Optimization techniques
- Memory-efficient training

**MCP Servers**:
- arXiv for paper discovery and analysis

**Tools Available**:
- read, webfetch, searchweb
- analysis, train (custom tools)

**Use Cases**:
- "Find recent papers on efficient attention mechanisms"
- "Analyze papers on learning rate scheduling for LLMs"
- "Research memory optimization techniques for training"

## Integration Details

### Tool Implementation

Custom tools are implemented as TypeScript files in `.opencode/tools/`:

- **train.ts**: Uses Bun shell to execute `./run.sh train`
- **analysis.ts**: Parses log files and results.tsv using regex patterns
- **build-image.ts**: Uses Docker commands via Bun shell

### Agent Configuration

Agents are configured as JSON files in `.opencode/agents/`:

- **python-coder.json**: System prompt + tools + permissions
- **arxiv-researcher.json**: System prompt + MCP servers + tools

### Project Documentation

- **AGENTS.md**: Initialized by `/init`, contains project context
- **program.md**: Human-editable instructions for the agent

## Troubleshooting

### Tools Not Recognized
- Ensure `.opencode/tools/` directory exists with TypeScript files
- Run `/init` in OpenCode to reload configuration

### Agent Not Found
- Check `.opencode/agents/` for JSON files
- Verify JSON syntax with a validator

### Build Fails
- Check Docker is running: `docker ps`
- Verify Docker Compose: `docker compose --version`
- Check permissions: `ls -la .opencode/`

### Results Not Found
- Ensure `run.log` exists after training
- Check `results.tsv` has proper format (tab-separated)
- Verify log contains `val_bpb:` metric

## Best Practices

1. **Naming Conventions**:
   - Experiment names: `experiment-<date>-<description>`
   - Branch names: `autoresearch/<date>-<description>`

2. **Logging**:
   - Always log to `results.tsv` after experiments
   - Include status: `keep`, `discard`, or `crash`

3. **Tool Usage**:
   - Use `train` with descriptive experiment names
   - Use `analysis` to check results before committing
   - Use `build-image` when dependencies change

4. **Agent Collaboration**:
   - Use `arxiv-researcher` to inform hypothesis
   - Use `python-coder` to implement changes
   - Always verify with `analysis` after experiments

## Advanced Usage

### Custom Tools

Add new tools by creating files in `.opencode/tools/`:

```typescript
// .opencode/tools/my-tool.ts
import { tool } from "@opencode-ai/plugin"

export default tool({
  description: "Tool description",
  args: {
    param: tool.schema.string().describe("Parameter description")
  },
  async execute(args, context) {
    // Your logic here
    return "result"
  }
})
```

### Custom Agents

Create new agents in `.opencode/agents/`:

```json
{
  "name": "custom-agent",
  "description": "Agent description",
  "system_prompt": "System prompt...",
  "tools": ["read", "bash", "custom-tool"],
  "mcp_servers": [],
  "permissions": {...},
  "model": "Qwen/Qwen3-Coder-Next"
}
```
